# Policy Reporter

Deploys [Policy Reporter](https://kyverno.github.io/policy-reporter) via Helm, managed by Argo CD.
Provides a web dashboard for `PolicyReport` / `ClusterPolicyReport` resources generated by
Kyverno's `reportsController`.

## Structure

```
application.yml     # ArgoCD Application — chart policy-reporter
values.yml          # Helm values (enables UI + ingress)
kustomization.yml   # Includes namespace.yml
namespace.yml       # policy-reporter namespace
```

## Dependencies

Requires `kyverno`'s `reportsController` to be enabled (it is — see `kyverno/values.yml`),
which generates the `PolicyReport`/`ClusterPolicyReport` resources this dashboard reads.
No Vault secrets are required.

## Deploy

```bash
kubectl apply -f policy-reporter/application.yml
# or
argocd app sync policy-reporter --prune --refresh
```

No Vault secrets are required for PolicyReporter itself.

## Verification

```bash
# App synced and healthy
argocd app get policy-reporter

# Pods running
kubectl -n policy-reporter get pods

# Confirm Kyverno is producing reports for the UI to display
kubectl get clusterpolicyreport
kubectl get policyreport -A
```

Visit `https://policy-reporter.apps.k8s.enros.me` (behind Authelia) to view the dashboard.
